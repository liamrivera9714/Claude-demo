# 烽火疆域

一个回合制六角格策略网页游戏。纯 HTML + Canvas，单文件，无需构建，直接用浏览器打开 `index.html` 即可游玩（手机也可以）。

## 玩法

- 你是蓝方，对手是 1–3 个电脑势力。攻下所有敌方都城获胜，自己的都城陷落则失败。
- 围城：单位停在敌方都城上开始围城，撑到它下回合开始仍在城中，都城才陷落。守方有一整回合反击，被围时在都城招的兵当回合就能进攻。城池的防御加成只给主人。
- 攻灭一国只得到它的城池和 15 金战利品，其余领土变回无主。
- 点自己的单位，再点亮起的格子移动；点红圈里的敌人进攻，圈上方是预计伤害，黄色“反”标是对方的反击。鼠标悬停在目标上，右侧会显示双方血量变化的战斗预估。
- 未选中任何东西时，右侧面板列出本回合的收入明细。
- 走过的格子归你所有。都城每回合 6 金，城镇 3 金，每 4 格领地 1 金，每个单位军饷 1 金。
- 点自己的都城或城镇招兵：步兵、弓兵、骑兵、盾卫，各有所长。
- 兵种相克：步兵克骑兵，骑兵克弓兵，弓兵克步兵。击溃敌军的单位会晋升，攻击更高。
- 夹击：目标身边每多一个己方单位，攻击 +1（最多 +2）。上一轮挨过打的单位不回血。
- 在都城或城镇旁的平原开垦农田增加收入；踏入敌方农田可以劫掠金币。
- 点敌方单位查看它下回合的威胁范围；本回合内的操作都可以悔棋。
- 森林减速并加防御，城镇和都城加防御，山和水不能通行。
- 轮到你时，地图上会画出敌方上一轮的移动箭头和交战位置；战报保留 30 条，可滚动查看。
- 键盘：空格切换下一个单位，回车结束回合，Z 悔棋，R 显示/隐藏敌方动向，Esc 取消选择。

进度自动保存在浏览器本地，可以在页面底部选择对手数量和难度重新开局。
